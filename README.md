# 🎬 Movie Cinema Management System

A simple, menu-driven **C++ movie cinema booking system** built as an OOP-based final project. It lets users browse movies, pick a cinema hall, reserve seats, and track total revenue — all from the terminal.

## ✨ Features

| Feature | Description |
|---|---|
| 🎞️ View Available Movies | Browse a catalog of movies with genre, duration, price, and rating |
| 🏛️ View Cinema Halls | See all halls and their seat layout |
| 💺 Interactive Seating Chart | Visual `O` / `X` grid for available vs. booked seats |
| 🎟️ Book a Ticket | Reserve a seat for a chosen movie and hall |
| 🚫 Double-Booking Prevention | Already-booked seats can't be booked again |
| 📋 View All Bookings | See every reservation made in the session |
| 💰 Track Total Revenue | Live running total of all ticket sales |

## 🚀 How to Run

### 1. Open a terminal in the project folder

### 2. Compile the program

```bash
g++ MovieCinema.cpp -o MovieCinema.exe
```

### 3. Run the program

**Linux / macOS**
```bash
./MovieCinema.exe
```

**Windows PowerShell**
```powershell
.\MovieCinema.exe
```

## 🧠 What You'll Learn

This project is a great hands-on introduction to core C++ / OOP concepts:

- ✅ Classes & Objects (`Movie`, `Hall`, `Seat`, `Booking`)
- ✅ Encapsulation with private members & getters
- ✅ Working with `std::vector` and nested containers
- ✅ Menu-driven program design with input validation
- ✅ Simple state management (bookings & revenue tracking)

- **Concepts:** Object-Oriented Programming, STL Containers
- **Compiler:** g++ (GCC)
